# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Lightchain / Orca app users. Primary audience is everyday wallet users and builders who want a calm, clear UI — not developer console density.

## Product Purpose

Crypto coaching / education app.

## Positioning

Part of the Orca / KeikoDev Lightchain app family. Keep the incumbent look; polish removes AI-slop tells without rebranding.

## Brand Commitments

Preserve each app's existing palette and layout language. Prefer clear hierarchy, readable type (≥12px UI chrome), and solid (non-gradient-clipped) titles.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast for body text. Large tap targets on primary actions. Mobile-friendly.
